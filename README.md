Open-source collection of Valheim mods, ranging from small quality-of-life tweaks to
larger gameplay changes.

## Information

This repository gathers every Valheim mod maintained here, each self-contained with its
own source code, build project, and packaged release files. Some mods are small, focused
tweaks (a single config option or behavior fix), while others may add broader gameplay
changes - check each mod's own README for scope and details. All of them are open source -
feel free to read, fork, or reuse the code.

- `mods/` - individual standalone mods, each in its own folder with its own source,
  packaged release files, and license.

## Mods

| Mod | Description |
| --- | --- |
| [HotbarDeathKeeper](mods/HotbarDeathKeeper/README.md) | Keeps vanilla hotbar items equipped after death instead of losing them to the tombstone. |

## Status & Support

These are hobby projects maintained in spare time - there's no fixed release schedule.
Updates and fixes happen whenever possible, not on a continuous or guaranteed cadence.
Some mods may contain bugs or unexpected behavior; if you run into an issue, please open
an issue on the mod's repository so it can be looked at when time allows.
